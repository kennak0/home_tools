# city — ちいさな街

タイルを置いて街を育てる、ひとり用のシミュレーションゲーム。スーパーファミコンの
街づくりゲームの操作感を、iPhone のホーム画面から 1 秒で開ける PWA に置き直す。
`pwa/` 共通の決め事は `.claude/AGENTS.md` の「PWA 開発ガイド」、
オフライン化の規則は `.claude/skills/offline-first-pwa/SKILL.md`。
このファイルは**このアプリ固有の仕様と判断**の正本。

## 権利について

既存作品の名称・キャラクター・グラフィックは一切使わない。**遊びの仕組み
（ゾーニング、電力、人口、災害）だけを参考にしたオリジナル作品**として作る。
タイルの絵はすべてコードで描いている（`tiles.js`）ので、外部素材への依存もない。
アルゴリズムの参考にする Micropolis は GPL-3 なので、**コードは移植しない**。
挙動を読んで自分で書く。

## 状態

**段階 0 まで実装済み。** 遊べるのは「地形の上に道路と住宅ゾーンを置き、資金が減る」ところまで。
シミュレーション（成長・人口・電力・時間）はまだ動かない。

**service worker と manifest はまだ無い**（普通の Web ページとして動く。オフライン起動・
更新バナーは無し）。段階 1 でシミュレーションが動き出したら `sw.js` と precache 生成
スクリプトを足す。`pwa/tools/gen-sw.mjs` は family-schedule と共用する予定。

## 段階

| 段階 | 内容 |
|---|---|
| **0（済）** | マップ生成・表示、タッチ操作（スクロール・ズーム）、道路・住宅ゾーンの設置と撤去、資金、自動保存 |
| 1 | 時間の経過（1 ティック = 1 ヶ月）、発電所と電力の伝播、ゾーンの成長、人口、税収。商業・工業ゾーン |
| 2 | 交通量・汚染・犯罪・地価の各マップ。警察署・消防署。グラフ画面 |
| 3 | 災害（火災・洪水）、人口達成でのボーナス建物、シナリオ、効果音 |

段階 1 に入るまでは家族に配らない（オフラインで起動できないため）。

## 遊び方（段階 0）

下のツールバーでツールを選び、地図をタップまたはドラッグする。

| ツール | 動作 | 費用 |
|---|---|---|
| 手のひら | 1 本指でスクロール | — |
| 道路 | ドラッグで連続して敷ける。水の上には引けない（橋は段階 1） | 10 |
| 住宅ゾーン | 3×3。9 マスすべてが陸で、建物が無いこと。木は自動で伐採される | 100 |
| 整地 | 道路・ゾーン・木を消す。ゾーンは 1 マス触れば 3×3 ごと消える | 1 |

**2 本指はツールに関係なく常にスクロールとピンチズーム**にした。ツール選択中に
1 本指で地図を動かそうとして誤って建ててしまうのを防ぐため。

## データモデル

マップは 120×100 = 12,000 マス。3 本の TypedArray を並べて持つ。

| 配列 | 型 | 内容 |
|---|---|---|
| `terrain` | `Uint8Array` | `LAND` / `WATER` / `TREE` |
| `build` | `Uint16Array` | `EMPTY` / `ROAD` / `ZONE_R` |
| `zone` | `Int32Array` | ゾーンを構成するマスは中心マスの添字。それ以外は `-1` |

3×3 ゾーンの各マスから中心を引けるように `zone` を別に持つ。中心マスは
`zone[i] === i`。これがあると「端を整地したらゾーンごと消える」「隣に重ねて置けない」が
どちらも 1 行で書ける。

道路の見た目（十字・曲がり・行き止まり）は**保存せず、描画時に隣 4 マスから毎回求める**。
保存すると隣を消したときの張り替え漏れが必ず出る。

保存は IndexedDB の `city` ストアにセーブスロット 1 個（`id: "slot1"`）。TypedArray は
structured clone でそのまま入る。`localStorage` は使わない（`.claude/AGENTS.md` の決め事）。
変更から 1 秒後にまとめて書く。

### family-schedule のデータ規則を適用しない理由

共通の決め事では「レコードごとに `id`/`updatedAt`/`deleted` を持たせる」としているが、
これは端末間で同期する予定表のための規則。ゲームのセーブは同期しない（ひとり用）ので、
マスごとにメタデータを持たせる意味がない。セーブ全体に `savedAt` だけ持たせる。

## 表示

`<canvas>` 1 枚。16×16 のタイルを `tiles.js` がコードで描いて 1 枚のアトラスに焼き、
描画は**画面に映っているマスだけ** `drawImage` する。iPhone の画面で常時 300 マス程度なので、
差分描画（ダーティタイル管理）は要らなかった。再描画は「カメラか地図が変わったとき」だけ
`requestAnimationFrame` で 1 回。指を止めれば描画も止まる。

拡大率は 1〜4 倍の連続値。ピンチ中は中間値を通るが、指を離した時点で整数に吸着させる
（ドット絵が等倍でないと汚いため）。`imageSmoothingEnabled = false`。

## 外部送信

**無し。** 通信は一切しない。CSP も `connect-src 'none'` にしてある。

## テスト

```bash
node pwa/tools/serve.mjs --no-cache   # http://localhost:8080/city/
```

`--no-cache` は `serve.mjs` に足したもの（既定は Pages と同じ `max-age=600`）。
**これを付けずに編集を繰り返すと、ブラウザが古いモジュールを掴んだまま**になり、
直したはずの不具合が消えない。それでも古い版が出るときは、`localhost` と
`127.0.0.1` が別オリジン扱いなのを利用して一方に切り替えると確実に読み直せる
（IndexedDB も別になるので、セーブは引き継がれない）。

- MCP の Firefox で開き、`list_network_requests` で**自分のファイル以外を取っていない**ことを確認する
- 拡大縮小・スクロールは**実機の iPhone でしか確かめられない**（ピンチ、safe-area、
  `-webkit-touch-callout`）。Firefox で通っても済みにしない
- 保存の確認は DevTools で IndexedDB の `city` → `saves` を見る。作り直すには
  「新しい街」ボタン（確認あり）

## 未実装・分かっている穴

- 取り消し（Undo）が無い。ドラッグで引きすぎた道路は整地で消すしかない
- 水面は埋め立てられない。橋も架けられない（段階 1 で道路に組み込む）
- セーブスロットは 1 個だけ
- 効果音なし
- `favicon.ico` が無く、読み込みのたびに 404 が 1 本出る。アイコンは段階 1 で
  manifest と一緒に足す
